Cultivation Setup & Data-Capture Checklist

Nursery-first. Every real clone-room document → the dashboard screen that populates it. Owner: Loraine (FACILITY_MANAGER).

Part A · One-time setup (do these first, in order)

  1. Add the cultivation team — System → Users. Nursery Manager + 4–5 Cultivators (Lou exists). So tasks can be assigned.
  2. Build the nursery / clone room — Cultivation → BayGrid → Add Greenhouse. Use the real bays × rows × spots (clone room is small — not the 520 default).
  3. Register the mother plants — Cultivation → Mothers. The genetics every clone + foliar log hangs off.
  4. Switch on the recurring schedules — the cleaning / temp-humidity / activity / foliar / jiffy forms then auto-fire daily to the team (TaskTemplate + calendar connector).
