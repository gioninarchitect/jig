PRE-LAUNCH REQUIREMENTS

0/6
  • Premises Ready Required
    Physical location secured, lease signed, security measures in place
  • Internet Connection Required
    Stable WiFi or 4G/LTE connection (minimum 10Mbps recommended)
  • Section 21 License Required
    Valid Section 21 exemption certificate for location
  • Branch Manager Identified Required
    Named person responsible for branch operations and compliance
  • Staff Recruited Required
    Minimum 2 staff members trained on products and compliance
  • Cash Float Prepared Required
    Opening float for cash transactions (recommended R2,000)
2

HARDWARE SETUP

0/7
  • Tablet Received Required
    Android tablet or iPad shipped from HQ with case and charger
  • Tablet Charged & Connected to WiFi Required
    Full charge, connected to store WiFi network
  • POS Bookmark Added Required
    Add to home screen for quick access
    https://origin.cleva-ai.co.za/pos.html?branch=BRANCH_CODE
  • Card Machine Setup Required
    Yoco/iKhokha device paired and tested with test transaction
  • Receipt Printer (Bluetooth) Optional
    58mm thermal printer paired to tablet (can use email receipts instead)
  • Cash Drawer Optional
    Lockable cash drawer for float and daily takings
  • Backup Power Optional
    UPS or power bank for load shedding resilience
3

SYSTEM CONFIGURATION (HQ)

0/5
  • Branch Created in Database HQ Action
    Branch document created with address, hours, contact info
    node scripts/seed-branches.js
  • Staff Accounts Created HQ Action
    Create user accounts for branch manager and staff
    node scripts/create-branch-staff.js SPR-001 0831234567 John Smith
  • Inventory Allocated HQ Action
    Transfer initial stock from HQ to branch inventory
    node scripts/allocate-stock.js SPR-001 50
  • Branch Activated HQ Action
    Activate branch and switch landing page to live store
    node scripts/activate-branch.js SPR-001
  • Payment Methods Enabled HQ Action
    Enable cash, card, EFT for branch in system settings
4

INVENTORY SETUP

0/5
  • Stock Shipment Received Required
    Initial product shipment from HQ with packing list
  • Physical Count Completed Required
    Count all received items against packing list, note discrepancies
  • Stock Verified in System Required
    Confirm system inventory matches physical count
  • Products Displayed Required
    Merchandise arranged on shelves/display cases with pricing
  • Section 21 Products Secured Required
    Medical cannabis products in locked storage, access controlled

STAFF TRAINING

0/6
  • POS System Training Required
    Login, find products, add to cart, process payment, issue receipt
  • Customer Registration Required
    Register new customers, verify age, collect phone number
  • Section 21 Protocol Required
    Verifying prescriptions, checking patient limits, compliance
  • Cash Handling Required
    Float management, end-of-day cash up, discrepancy reporting
  • Product Knowledge Required
    Product categories, THC/CBD content, recommendations
  • Refund/Exchange Policy Required
    When refunds are allowed, manager approval requirements

PRE-LAUNCH TESTING

0/7
  • Staff Login Test Required
    All staff can login to POS with their credentials
  • Product Search Test Required
    Can find products by name and category
  • Cash Sale Test Required
    Complete test cash transaction, verify receipt
  • Card Sale Test Required
    Process test card payment, verify in system
  • Inventory Deduction Test Required
    After test sale, verify stock quantity reduced
  • Customer Registration Test Required
    Register test customer, verify they appear in system
  • End-of-Day Report Test Required
    Run daily report, verify totals match

GO LIVE DAY

0/7
  • HQ Notified of Launch Required
    Confirm with HQ that branch is ready
  • Staff On-Site Required
    Branch manager + minimum 1 staff member present
  • Cash Float in Drawer Required
    Opening float counted and recorded
  • Card Machine On & Connected Required
    Device powered, paired, and ready
  • POS Logged In Required
    Tablet on, POS loaded, staff logged in
  • First Real Sale Completed Required
    Successfully processed first customer transaction
  • HQ Confirmation Required
    Report to HQ that branch is live
