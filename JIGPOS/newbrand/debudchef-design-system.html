Usage Guidelines

Do's and don'ts for brand consistency

✓ Do
  • Use Passion One for all headlines in uppercase
  • Apply gold accents sparingly for emphasis
  • Maintain generous white space
  • Use the green gradient for primary backgrounds
  • Keep taglines in Crimson Pro italic
  • Use embedded SVG icons for reliability
✗ Don't
  • Use Passion One in lowercase
  • Mix brand colors with off-palette colors
  • Stretch or distort the logo
  • Use low-contrast color combinations
  • Place logo on busy backgrounds
  • Use fonts outside the type system
