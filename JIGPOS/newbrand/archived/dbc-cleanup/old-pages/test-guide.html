Database Role Schema

These are the roles defined in the User model schema:

Admin Role

role: 'admin'

Full system access including user management, product management, and system settings.

Store Manager

role: 'branch_manager'

Branch management, inventory control, staff supervision, POS system, and reporting.

Staff Assistant

role: 'branch_assistant'

Point of sale operations, bartender duties, and basic customer service functions.

Customer/User

role: 'user'

Standard customer account. Section 21 status determines medical cannabis access.

Section 21 Authorization

  • Section 21 Status: Separate from user role
  • Pending: Application submitted, awaiting admin approval
  • Approved: Access to medical cannabis products
  • Expired: Authorization requires renewal
