Daily Operations
Opening, Running & Closing the Branch
SOP-001: Branch Opening Procedure
Branch Manager / Senior Staff 15-20 min Daily

Purpose: Ensure the branch is properly prepared for trading, all systems are operational, and the opening float is verified.

  1. Arrive 30 minutes before trading hours
    Unlock premises, disarm alarm, visual walk-through for security.
  2. Power on POS terminals, check internet
    If offline, system operates in offline mode — continue as normal.
  3. Log in with your PIN, start shift
    Use your personal PIN. Never share PINs.
    POS → Enter PIN → Start Shift
  4. Count the opening cash float physically
    Count every denomination. Standard float per branch (typically R500-R1,000).
  5. Record float in POS
    Enter exact amount counted. System compares to expected float.
    POS → Shift Management → Record Float
  6. Check product display, restock if needed
  7. Review overnight orders/notifications
    POS → Dashboard → Notifications
  8. Open for trading at scheduled time
Do Not Skip the Float Count

If opening float doesn't match expected, record the actual amount and notify the Branch Manager or Owner immediately.

Opening Checklist

  • Premises unlocked, alarm disarmed
  • POS terminals powered on and operational
  • Logged in with personal PIN
  • Shift started in system
  • Cash float counted and recorded
  • Product display checked and restocked
  • Notifications reviewed
  • Branch open at scheduled time
SOP-002: Shift Handover Procedure
All Staff 10 min Daily (if applicable)
  1. Outgoing: Complete all pending transactions
  2. Outgoing: Count till cash, record mid-shift count
    POS → Shift Management → Mid-Shift Count
  3. Both: Verify cash together (independent count)
    Both totals must match. If not, recount.
  4. Outgoing: End shift in system
  5. Incoming: Log in, start shift, record float
  6. Verbal briefing: issues, low stock, pending orders
Both Staff Present for the Count

The joint count protects both parties from blame. Never hand over without both people counting.

SOP-003: Branch Closing & Day-End
Branch Manager / Closing Staff 20-30 min Daily
  1. Stop accepting customers at closing time, lock door
  2. Complete all pending transactions
  3. View day's sales summary
    POS → Reports → Daily Sales Summary
  4. Count all cash by denomination
    Write down total before entering in system.
  5. Perform cashup in POS
    Enter actual cash. System shows expected vs actual + variance.
    POS → Cashup → Enter Denominations → Submit
  6. Investigate any variance > R20
  7. Separate float from takings, secure in safe
  8. End shift, secure premises, set alarm
The Cashup Is NOT Optional

Every trading day ends with a completed cashup. "I'll do it tomorrow" is not acceptable. An incomplete cashup means the day's finances are unverified.

Closing Checklist

  • All customers served, door locked
  • All transactions completed or voided
  • Sales summary reviewed
  • Cash counted (before entering in system)
  • Cashup submitted in POS
  • Variance investigated (if > R20)
  • Float separated, takings secured
  • Shift ended, alarm set, premises secured
POS & Sales
Processing Transactions
SOP-004: Processing a Sale
Sales Assistant 2-3 min Every Transaction
  1. Greet customer, check if returning (loyalty) or medical (Section 21)
  2. Search/select customer or proceed as guest
    POS → Customer Search → Select or "Guest Sale"
  3. Add products to cart
    Search by name/category or scan barcode. Do not sell more than in-stock qty.
  4. Review cart with customer, apply discounts if applicable
  5. Select payment method and process
    Cash: enter tendered amount. Card: process terminal. EFT: confirm received.
    POS → Checkout → Select Payment → Complete
  6. Issue receipt (print or digital)
  7. Thank customer, offer loyalty sign-up
Zero Tolerance: Off-System Sales

Any sale not through POS is unauthorized: cash in pocket, manual receipt, IOUs. All are disciplinary offences.

SOP-005: Refunds & Void Transactions
Branch Manager (approval required) As Needed
  1. Customer requests refund — ask for receipt, verify in POS
  2. Verify eligibility (unopened, within return window)
  3. Request Branch Manager approval in system
  4. Manager reviews, approves/denies with documented reason
  5. Process refund in same payment method as original
  6. Return product to inventory (if resalable) or mark as waste
Void vs Refund

Void: Cancel before completion (wrong item). Refund: Reverse after completion (product return). Both require manager approval.

SOP-006: Customer Registration & Loyalty
Sales Assistant 2 min
  1. Ask customer to join loyalty program (required for medical)
  2. Collect: name, phone, email. Medical: also Section 21 number, doctor
  3. Enter in POS, double-check phone number
    POS → Customers → New Customer
  4. Link current sale to new profile
Cash Handling
Cash Rules & Reconciliation
SOP-007: Cash Handling Rules
All Staff Handling Cash Always

Golden Rules

  1. Never leave till drawer open unattended
  2. Count change back to customer aloud
  3. Never put personal money in till or take till money out
    Not even temporarily. Treated as theft regardless of intent.
  4. Report suspected counterfeit notes immediately
  5. Regular cash drops to safe when till exceeds maximum
    POS → Cash In/Out → Cash Drop to Safe
  6. All cash movements recorded through POS
No IOUs, No Tabs, No "I'll Pay Later"

No credit sales at branch level. If customer can't pay, they can't take product. No exceptions.

SOP-008: Daily Cashup & Reconciliation
Branch Manager 10-15 min Every Trading Day
  1. Open Cashup module
    POS → Cashup
  2. Count every denomination physically
    R200, R100, R50, R20, R10 notes; R5, R2, R1 coins; smaller coins. Calculate total.
  3. Enter denomination counts in POS
    System calculates: opening float + cash sales - refunds - drops = expected.
  4. Review variance (Actual - Expected)
  5. If variance > R20: investigate before submitting
  6. Submit cashup (locks the day's record)
  7. Escalate persistent variances (3+ consecutive days)

Variance Response Guide

VarianceActionEscalate To
R0 – R20Normal rounding. Submit as-is.None
R21 – R100Recount. Check transactions. Document.Manager notes
R101 – R500Recount. Full audit. Written report.Owner same day
R500+Don't submit. Recount with witness.Owner + partner immediately
Stock & Receiving
Stock Management Procedures
SOP-009: Receiving Stock Deliveries
Branch Manager / Inventory Manager 15-30 min Per Delivery
  1. Receive delivery note, match to pending PO
    No matching PO? Do not accept — contact Inventory Manager.
  2. Open Stock Receiving module
    POS → Stock Receiving → Select PO
  3. Count and verify every item physically
    Open every box. Count every unit. Don't trust the delivery note — count yourself.
  4. Enter received quantities (actual count, not PO qty)
  5. Record discrepancies, photograph damaged goods
  6. Sign delivery note ONLY after verification, submit in system
  7. Store products properly (FIFO: first in, first out)
Never Sign Before Counting

Once you sign, you accept responsibility for stated quantities. Shortage after signing = the business absorbs the loss.

SOP-010: Inter-Branch Stock Transfers
Inventory Manager / Branch Manager As Needed

Sending Branch

  1. Create transfer request (destination, products, quantities)
    Inventory → Transfers → New Transfer
  2. Wait for approval from Inventory Manager/Owner
  3. Pick, count against transfer doc, pack securely
  4. Mark as dispatched (sending stock levels reduced)

Receiving Branch

  1. Receive notification of incoming transfer
  2. Count received items physically
  3. Confirm receipt in system with actual quantities
No Stock Moves Without a System Record

Product brought from another branch without a transfer record = do not accept. Escalate to Inventory Manager.

SOP-011: Stock Discrepancy Investigation
Branch Manager / Inventory Manager When Found
  1. Identify the discrepancy (stocktake, cashup, spot check, auto-recon)
  2. Recount affected products in all locations
  3. Check transaction history (sales, receiving, transfers, waste)
    Inventory → Product → Transaction History
  4. Document: product, unit difference, probable cause, action
  5. Adjust stock ONLY with Inventory Manager/Owner approval
Never Adjust Without Investigation

Flow: Identify → Recount → Investigate → Document → Adjust (with approval). Never jump to adjusting.

Stocktake
Physical Inventory Counts
SOP-012: Full Branch Stocktake
Branch Manager + Team 2-4 hours Monthly

Before

  1. Schedule 1 week in advance, notify all staff
  2. Assign counting zones (sales floor, backroom, display, safe)
  3. Process all pending receiving and transfers first
  4. Open stocktake session in app
    Stocktake App → New Session → Full Stocktake

During

  1. Count every item physically (no estimates, open sealed boxes)
  2. Enter counts in app (BLIND — expected qty not shown)
  3. Do NOT adjust counts to match expectations
    If you count 47, enter 47 — even if system expects 50.
  4. Flag damaged, expired, or unknown products

After

  1. Review and submit session
  2. Review variance report (focus on > 5% or > 3 units)
  3. Investigate discrepancies per SOP-011
  4. Report results to Owner

Full Stocktake Checklist

  • Staff notified 1 week in advance
  • Zones assigned
  • All receiving/transfers processed
  • Trading paused during count
  • Session opened in app
  • All items physically counted (blind)
  • Damaged/expired flagged
  • Session submitted
  • Variances reviewed
  • Discrepancies investigated
  • Results reported to Owner
SOP-013: Weekly Spot Stock Check
Branch Manager 15-30 min Weekly
  1. Select 10-15 products (best-sellers, high-value, previous issues, random)
  2. Open spot-check session in app
    Stocktake App → New Session → Spot Check
  3. Count selected products, enter actual counts (blind)
  4. Submit, investigate any significant variances per SOP-011
Why Spot Checks Work

Faster, less disruptive, catches issues early. Keeps staff aware stock is monitored — deters theft.

Incidents
Exception & Emergency Handling
SOP-014: System Outage / Offline Operations
All Staff When System Down
  1. Check if POS is in offline mode (banner at top)
    Sales continue as normal — saved locally, syncs when back online.
  2. Continue processing sales in offline mode
  3. Card payments: use terminal independently if it has connectivity
  4. Report outage to implementation partner (time, nature)
  5. When back online: verify sync, report any missing transactions
Offline Mode Is NOT an Excuse for Manual

POS, Stocktake, and Dispatch apps all work offline. "Internet is down" never means "use paper."

SOP-015: Customer Complaint Handling
All Staff (escalate to Manager) As Needed
  1. Listen fully without interrupting
  2. Apologize and take ownership
    "I'm sorry about this experience. Let me see what I can do."
  3. Resolve if possible (exchange, partial refund with approval)
  4. If can't resolve: escalate to Branch Manager
    Never tell a customer "there's nothing I can do."
  5. Record complaint in system (date, name, issue, resolution)
SOP-016: Security Incident Procedure
All Staff Emergency

During

  1. Your safety comes first — do not confront anyone
  2. Activate panic button / call security / SAPS (10111)
  3. Remember details after they leave (count, appearance, direction)

After

  1. Ensure all staff and customers are safe
  2. Call Branch Owner and implementation partner
  3. Preserve scene for SAPS — don't touch anything
  4. After police clear: emergency spot check (SOP-013)
  5. File incident report with SAPS case number
