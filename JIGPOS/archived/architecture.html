System Architecture

Tech stack, database, and core infrastructure

Backend

Node.js with Express.js framework. RESTful API architecture with JWT authentication.

Database

MongoDB with Mongoose ODM. 16 models covering users, products, orders, batches, and more.

Authentication

OTP email authentication with 6-digit codes. JWT tokens with 24-hour sessions. Multi-device support.

Email Service

Nodemailer with SMTP. OTP delivery, order confirmations, marketing campaigns.

Queue System

Bull with Redis backend for background jobs, scheduled tasks, and campaign processing.

Security

Helmet, CORS, rate limiting, mongo-sanitize. OTP attempt tracking and session management.
