Bug Tracker Testing

Submit Bug Report

  • Click black bug button (bottom right on any page)
  • Select bug type: Bug, UI Issue, Data Issue, Performance, Feature
  • Set priority: Low, Medium, High, Critical
  • Enter description and steps to reproduce
  • Optional: Click "Select Area" for screenshot
  • Submit bug report successfully

View Bug Reports

  • Access dashboard view at /bug-dashboard.html
  • Access kanban board at /bug-kanban.html
  • Filter by type, priority, status
  • View screenshots (click to enlarge)
  • View network logs and console errors

Manage Bugs

  • Change bug status: New → In Progress → Review → Resolved
  • Drag and drop in Kanban view
  • Export bug to JSON for AI analysis

Export for AI Analysis

  • Click "Export JSON for AI" button on any bug
  • Download JSON file with AI analysis instructions
  • Copy JSON contents and paste into Claude Code/ChatGPT
  • AI analyzes root cause and suggests fixes
