High Priority Issues

BUG-001
Regular User Login Failure
Login Page
High Resolved

Description

Users were unable to log in using the regular user test account (user@basothomedicalherbs.ls).

Root Cause

The pending user account had an invalid loyalty tier value ("bronze") which is not in the User model enum. Valid values are: wellness_seeker, wellness_advocate, wellness_champion, wellness_elite.

Resolution

Updated the user's loyalty.tier field in the database from "bronze" to "wellness_seeker".

Test This Fix

1. Click button below
2. Login with: user@basothomedicalherbs.ls / User123!
3. Verify dashboard loads

Reported: 23 Nov 2025 | Fixed: 25 Nov 2025
BUG-002
POS Payment Methods Not Working
Point of Sale
High Resolved

Description

None of the 4 payment methods (Cash, Card, EFT, InstaPay) were working when processing POS transactions.

Root Cause

The Sale model requires a valid "track" field with enum values of "lifestyle" or "medical". Test data was sending invalid values causing validation errors.

Resolution

API works correctly with valid data. All payment methods tested and verified working. Invoice and receipt PDF generation confirmed operational.

Reported: 23 Nov 2025 | Verified: 25 Nov 2025
BUG-003
Product Search Returns 500 Error
Products Page
High Resolved

Description

Search bar was not functioning - any search query resulted in a 500 server error.

Root Cause

Backend products search endpoint had issues with query parameter handling and MongoDB text search configuration.

Resolution

Fixed the search endpoint in backend/routes/products.js to properly handle search queries and return results.

Medium Priority Issues

BUG-004
Dashboard "Shop Now" Button Invisible
Customer Dashboard
Medium Resolved

Description

The "Shop Now" button under Quick Actions on the dashboard was only visible when hovering over it. Moving the mouse away made the button completely white/invisible.

Root Cause

CSS styling had white text on white background for the button's default state.

Resolution

Updated button styling in dashboard.html to ensure proper contrast and visibility in all states.

BUG-005
Section 21 Stuck on "Checking Prescription Status"
Patient Dashboard
Medium Resolved

Description

Medical prescription section would get stuck showing "Checking prescription status..." indefinitely, preventing access to medical products.

Root Cause

Section 21 is a third-party integration. The frontend was calling a non-existent endpoint, causing the loading state to hang.

Resolution

Redesigned Section 21 integration to show:

  • Greyed-out medical products carousel with "Section 21 Required" badge
  • Modal popup explaining the verification process
  • "Integration Coming Soon" notice with contact options
  • 5-second timeout to prevent indefinite loading

BUG-006
Cart Badge Shows White Circle (No Count)
Products Page
Medium Resolved

Description

When adding items to cart, the cart badge in the top right corner showed as a white circle without displaying the item count.

Root Cause

CSS in products.html had white text (#fff) on white background (#FFFFFF) for the cart-count class.

Resolution

Updated cart badge CSS to use black text (#000000) with a dark border for visibility.

.cart-count { background: #FFFFFF; color: #000000; border: 1px solid #333333; font-weight: 700; }
