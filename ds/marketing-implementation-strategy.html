04 — WEB INTELLIGENCE
scrape.do Integration
All web scraping powered by scrape.do API — replacing Firecrawl for competitor analysis, site auditing, and content extraction.

🌐 Site Scraping

Fetch any URL with JavaScript rendering, proxy rotation, and anti-bot bypass. Extract clean HTML/text for AI analysis.

🕵 Competitor Intel

Scrape competitor websites to extract pricing, features, messaging, and positioning for competitive analysis reports.

📊 SEO Data

Extract meta tags, heading structure, schema markup, link profiles, and page speed indicators for SEO audits.

📄 Content Extraction

Pull blog posts, landing page copy, and product descriptions for brand voice analysis and copy optimization.

🔑 API Configuration

scrape.do API key configured. Base URL: https://api.scrape.do?token=YOUR_KEY&url=TARGET. Supports JS rendering, residential proxies, and custom headers. Rate limit: 100 req/min on standard plan.
