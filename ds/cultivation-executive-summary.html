Technology Stack
Built on the proven Origin POS platform — same auth, same database, same deployment

Frontend

Vanilla JS + Chart.js. Responsive single-page app with hash-based navigation. Bootstrap grid. Cinzel + Inter typography.

Backend

Node.js + Express. 5 Mongoose models, controller + route architecture. RESTful API with JWT authentication.

Database

MongoDB with Mongoose ODM. Compound indexes for performance. Pre-save hooks for auto-calculations (VPD, yield%).
