The control that runs through it all — container tracking

Weight at every zone
Every container (bin → rack → bag → jar) is weighed at each hand-over. Variance beyond expected loss auto-alerts all senior roles — diversion control.
Handover with sign-off
A different person per zone; each hand-over is signed and audit-logged. No gaps in the chain.
Batch-linked
Everything carries the batch # (B-2026-NNN) from cultivation → genealogy preserved to the gram.
Forms auto-fire
Cleaning, drying logs, weight verification — auto-scheduled to Processing for sign-off, no paper.
The shift for Processing: clipboards, weigh-and-write, re-key, file → scan → weigh → sign. The chain builds itself.

Intake & Drying

Harvest received · dry room

What happens

Harvest intake
The harvest request from cultivation lands as a batch; wet weight captured into a container with a QR.
Dry-room conditions
Temp & humidity logged on schedule; the dry-room cleaning & sanitation form auto-appears daily.
Weight tracking
Container weighed in and out → drying loss recorded; abnormal loss auto-flags.
Container moves
Each move (zone → zone) is scanned + signed — the location is always known.
Paper: Drying log · Dry-room cleaning · Weight sheet → auto tasks + container weigh-events

Trim

Trim room · crew + weights

What happens

Trim sessions

03

Cure → Lab / COA

Curing jars · testing · release

What happens

Curing
Cured in QR jars; container events track each open/weigh; conditions logged.
Lab testing
Lab results captured per batch (potency, micro, etc.); pass/fail recorded → batch quarantined until cleared.
COA issued
On pass, the Certificate of Analysis is issued with a QR — the release evidence.
QA sign-off
Responsible Pharmacist / QA signs the release; a compliance ticket blocks release without it.
Paper: Cure log · Lab submission · COA · Release form → digital lab result + COA + gated QA sign-off

Release & Dispatch

Transport manifest · to retail / export
Released product
Only COA-cleared, QA-signed batches can dispatch — enforced, not optional.
Transport manifest
Manifest with batch #s, vehicle, transporter, route; expected vs actual transit auto-flags.
To Origin Retail / export
Batch release syncs to the POS / export pack; full genealogy travels with the product.
Destruction (if needed)
SAPS-witnessed destruction events captured with weight + officer + photo evidence.
