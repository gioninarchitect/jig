STEP 01

What we grow. Each strain has genetics, expected yield, THC/CBD profile, flowering time. The strain database tracks performance across all batches over time.

STEP 02
Mother Plant
The source of all clones. Each mother has an identifier (M01, M02), status (Active/Stressed/Culled), health timeline, and clone history. Mothers live in the mother bay with dedicated care.

STEP 03
Clone
Cuttings taken from a mother. Each clone gets an auto-generated ID (M01-01, M01-02...). Goes into a clone tray in the nursery. 14-day rooting period. Mortality tracked per clone with root cause. Three purposes: Production, R&D, Client.

STEP 04
Greenhouse
Surviving clones get transplanted to a greenhouse. Each greenhouse (GH1, GH2) has multiple bays. The BayGrid shows a visual overview of all greenhouses and their status.

GH2 — Flower — 6 bays — 2/6 active

STEP 05
Bay (with Rows)
Each bay has 4 rows × 2 positions = 8 fixed spots. Each spot has a permanent ID (B1-R1P1). Clones are allocated TO spots. Rows can have mixed strains. The grow calendar drives daily tasks per bay.

Plants grow through phases: Veg (14-16 days) → Flip → Flower (56 days). Daily tasks from the grow calendar: scouting, feeding, topping, defoliation, spraying. Clone IDs become active plant IDs (ZA-XXXXXX) at transplant.

When does the BATCH get created?

The batch number encodes Strain + Mother + Clone Date. But at which point in the flow does it become a batch?

OPTION A — AT CLONING

Strain → Mother → Clone → Batch → GH → Bay

Batch created when clones are cut. The batch follows the clones through the greenhouse. Batch = a group of clones from the same mother on the same day.

OPTION B — AT HARVEST

Strain → Mother → Clone → GH → Bay → Harvest → Batch

Batch created when plants are harvested. The batch is the harvested material entering processing. Clones have no batch until they're cut.
