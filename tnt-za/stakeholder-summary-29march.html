Smart Clone Tracking — Zero Extra Work for Staff

Staff ActionSystem Auto-Does
"20 cuttings from M01"Creates M01-01 to M01-20 automatically
"Day 7 root check ✓" (one tap)Bulk marks all 20 as checked
"16 survived, 4 died — root rot"16 → ROOTED, 4 → CULLED + mortality record
"Transplant to GH1 Bay 1"16 plant records created (ZA-XXXXXX), bay allocated, clone IDs activated

Three clone purposes: Production (grow→sell), R&D (new mothers), Client (sell clones directly)

Ticket System — The Operational Heartbeat

4 Ticket Types

  • Issue — problem found (pest, equipment, anomaly)
  • Requisition — need supplies/equipment (with Rand cost)
  • Approval — compliance document needs sign-off
  • RP Sign-off — pharmacist must approve

Status Colors

  • 🔴 Red — Open (needs action)
  • 🟡 Yellow — In Progress (being worked on)
  • 🟢 Green — Closed (completed)

Organised by workflow stage in accordion view.
Each role sees only their relevant stages.

Key Management Features

For FM / Head of Cultivation

  • Task Board (Kanban) — drag tasks between To Do / In Progress / Done
  • Role-filtered tabs — My Tasks, My Team, Cultivation, Processing, QA, All
  • Shift Allocation — assign staff roles + tasks per day via grow calendar
  • Role Switching — FM can change any staff member's role instantly

For Tenant Admin (Ilze)

  • Approval queue — all requisitions, compliance docs, RP sign-offs in one view
  • Staff overview — team count by role
  • Risk gauges — diversion, compliance, weight integrity scores
  • Site Master File — live SAHPRA document, export PDF anytime

For Staff (Workers / Trimmers / Housekeeping)

Simplest possible experience: Staff opens app at shift start → sees "My Shift" → their role for today + task list → Start Shift → check off tasks → if issue, add deviation notes → Complete Shift. No navigation. No searching. One screen.

Mortality & Root Cause Tracking

Every death is recorded with one of 15 root causes:

  • Pest
  • Mould
  • Root Rot
  • Nutrient Burn
  • Nutrient Deficiency
  • Overwatering
  • Underwatering
  • Light Stress
  • Heat Stress
  • Cold Stress
  • Genetic
  • Transplant Shock
  • Mechanical Damage
  • Disease
  • Unknown

Each record tracks: preventable (yes/no), corrective action taken, phase when death occurred. FM reviews all mortality records. Stats show: total deaths, monthly trend, clone mortality %, preventable %, top cause.
