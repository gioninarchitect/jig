System Overview

What it does

Operational control

  • Role-based dashboards for daily work.
  • Workflow tracking for submissions, approvals, and follow-up tasks.
  • Notifications and pending-action queues.
  • Audit trails for who did what, when, and under which role.

Documentation control

  • Central document library for site-level records.
  • Version and status visibility.
  • Digital Site Master File as the governed internal evidence record mapped to EU GMP.
  • Export and inspection-readiness views.

Digital Site Master File

Key value area

How to position it

EU GMP is the sole source of truth for compliance requirements. The Digital Site Master File is the governed internal record that maps site evidence to those EU GMP requirements. QMS, labels, batch records, training, annual medicals, deviations, process validation, signatures, and audit trails feed evidence into it.

Key points

  • Stores essential regulatory and operational documents.
  • Organized by site, study, document type, and status.
  • Supports version control and status visibility.
  • Tracks who uploaded, reviewed, approved, or changed each document.
  • Highlights missing, expired, pending, or approved documents.
  • Supports audit and inspection readiness.
  • Generates the Quality Manual / inspection pack from controlled records mapped to EU GMP.

Value Message

Use this wording
The value of the platform is that EU GMP remains the sole source of truth, while all site evidence feeds one governed Digital Site Master File mapped to those requirements. Instead of relying on email chains, manual trackers, or duplicate quality manuals, each role acts in the workflow while the Digital SMF remains complete, current, and inspection-ready.
