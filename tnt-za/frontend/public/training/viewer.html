TnT-ZA Training Guide

Read-only access for regulatory inspectors, auditors, and investors. You can see all the data but cannot create or modify anything.

This is a read-only account. You can browse all plant, container, batch, and audit data. You cannot register plants, submit results, or resolve anomalies.
Getting Started

How to Log In

▼
  • Go to https://tntilco.cleva-ai.co.za
  • Enter your email → 6-digit PIN → log in

What You See (Level 0 — Read Only)

▼
  • Dashboard — KPIs, risk gauges, activity feed, phase chart
  • Plants — Full registry with search, filter, plant detail + genealogy
  • Containers — All containers with event timelines and weight charts
  • Batches — Batch cards, lab results, chain of custody
  • Audit — Immutable audit log

You do not see: Scan, Facilities, Lab, Compliance, QMS, Security, or Users.

What You Can Review

Plant Traceability

▼
  • Search any plant by ID (ZA-XXXXXX), strain, or RFID
  • View the full phase timeline with weights at each stage
  • See the genealogy — mother plant and clones
  • See which batches the plant belongs to

Container Chain of Custody

▼
  • Click any container to see the full event timeline
  • Every LOAD, UNLOAD, MOVE, WEIGH, and HANDOVER is recorded
  • Each event shows: timestamp, weight, handler name(s), zone
  • A weight-over-time chart shows the container's journey

Batch Lab Results & COA

▼
  • Click any batch to see the 8-test protocol grid
  • Each test shows pass/fail/pending with values
  • If a COA has been issued, you can download the PDF
  • The chain of custody shows every container event linked to the batch

Audit Trail

▼
  • The Audit page shows every action in the system
  • Each entry: timestamp, user, action, entity type
  • The trail is append-only with SHA-256 hash chain — tamper-evident
  • You cannot modify or delete any entry
For SAHPRA Inspectors

What to Check During an Inspection

▼
  • Dashboard risk gauges — Diversion Risk should be low, Compliance Score should be high
  • Weight variance alerts — Any open (unresolved) anomalies are a concern
  • Audit trail — Verify the hash chain hasn't been broken (Super Admin can run verification)
  • Batch COAs — Every released batch should have a valid COA with all 8 tests passing
  • Plant genealogy — Verify mother plant records match physical inventory
  • Container timelines — Spot-check weight consistency across zone transitions
