Cultivator

TnT-ZA Training Guide

You are on the ground. You register plants, transition phases, weigh product, load containers, and hand material to the next person. Your actions create the data trail.

You don't receive weight alerts — you create the events that trigger them. Every weight you record is compared against the previous. Accuracy is critical.
Getting Started

How to Log In

▼
  • Go to https://tntilco.cleva-ai.co.za
  • Enter your email → check for 6-digit PIN → enter PIN
  • Session lasts 24 hours
Plant Lifecycle (Your Primary Workflow)

Registering a New Plant

▼
  • Go to Plants → Register Plant
  • Enter strain, select facility, select zone (Grow Room)
  • Optionally link a mother plant (for clones/genealogy)
  • System auto-generates: ZA-XXXXXX ID + RFID tag + QR code
  • The facility quota is checked — if full, registration is blocked

Phase Transitions

▼

Phases move in strict order. You cannot skip a phase.

  • SEEDLING → VEGETATIVE — no weight required
  • VEGETATIVE → FLOWERING — no weight required
  • FLOWERING → HARVESTED — WEIGHT REQUIRED
  • HARVESTED → DRYING — WEIGHT REQUIRED
  • DRYING → CURING — WEIGHT REQUIRED
  • CURING → PROCESSING — no weight required
  • PROCESSING → PACKAGED — WEIGHT REQUIRED

Use the Scan page to photograph the plant tag, then tap "View Details" and update the phase.

Scanning Plants

▼
  • Open Scan from the sidebar
  • Photograph the plant's tag (shows ZA-XXXXXX)
  • Claude Vision reads the ID and pulls up the record
  • You see: strain, current phase, zone, handler, weights
  • From here you can transition the phase or flag an issue
Container Operations

Loading a Container

▼
  • Scan the container label (e.g., BIN-001)
  • Select LOAD action
  • Weigh the product on the scale — photograph the scale display
  • Enter the weight and zone
  • Container status changes to LOADED

Moving a Container

▼
  • Scan the container
  • Select MOVE
  • Weight is mandatory at every zone transition
  • Photograph the scale — enter weight and destination zone
  • System compares weight to previous. If loss > threshold → alert fires to management

Handover to Next Person

▼
  • When transferring a container to the Facility Manager or next zone handler
  • Scan container → select HANDOVER
  • Enter the incoming handler's ID and the weight
  • Both your ID (outgoing) and theirs (incoming) are recorded
  • This creates a chain-of-custody entry
Other Tasks

Flagging a Non-Compliant Plant

▼
  • If you spot mould, pest damage, or other issues
  • Scan the plant → View Details → Flag Issue
  • Enter the reason — plant status changes to FLAGGED
  • Facility Manager is notified

Raising a Deviation

▼
  • If you deviated from an SOP (e.g., different drying temperature)
  • Go to QMS → Deviations → Create
  • Select the SOP, describe what happened, set severity
  • The FM will add root cause analysis and CAPA
