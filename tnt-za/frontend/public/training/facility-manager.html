Facility Manager

TnT-ZA Training Guide

You run the day-to-day operations at the facility. Container management, batch creation, destruction events, SOPs, and anomaly resolution all flow through you.

You are the primary anomaly resolver. Weight variance alerts come to you. You must investigate and document what happened — investigation notes are mandatory.

Container Workflow (Your Core Job)

The Container Lifecycle

▼

Every container must be weighed at every step:

  • LOAD — Cultivator loads product into container in Grow Room. Weight recorded.
  • MOVE — Container moves to Drying Room. Weight mandatory. System compares to LOAD weight.
  • HANDOVER — You receive from Cultivator. Both handler IDs recorded. Weight checked.
  • UNLOAD — Product removed from container. Weight compared. If variance > threshold → ALERT.

Use the Scan page to photograph the container label. The system identifies it and shows the current state.

Resolving Weight Variance Anomalies

▼

When an alert fires:

  • Go to Compliance → Open Anomalies
  • Click the anomaly → Review container ID, weight in/out, percentage loss
  • Investigate: check scale calibration, interview handler, review camera footage
  • Click Resolve and enter detailed investigation notes
  • Notes are mandatory — you cannot close without them
Batch & Lab Management

Creating Batches

▼
  • Batches are created from harvested plants (same strain, same facility)
  • The system auto-generates a batch number: B-2026-XXX
  • Total weight is calculated from the plants' harvest weights

SAPS Destruction Events

▼
  • Go to Compliance → Destruction
  • Record: batch/plant, weight, reason, SAPS officer name, badge number, station
  • If destroyed weight differs from recorded weight by >2%, an INVENTORY_DISCREPANCY anomaly fires
  • A separate confirmation step is required after recording
QMS

SOPs, Deviations, Equipment

▼
  • SOPs: Create and version SOPs. Staff acknowledge each version.
  • Deviations: When someone deviates from an SOP, record it with severity. Add root cause and CAPA, then close.
  • Equipment: Register scales and instruments. Record calibration dates. System alerts when calibration is due within 7 days.
Daily Routine

Morning Checklist

▼

  • Review any overnight notifications
  • Check container statuses — any STALE containers?
  • Verify equipment calibration schedule
  • Brief cultivators on today's phase transitions
