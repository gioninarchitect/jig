Security Officer

TnT-ZA Training Guide

You control the gate. Transport departures, arrivals, and SAPS destruction witnessing flow through your hands.

Getting Started

How to Log In

▼

  • Enter email → 6-digit PIN → log in

Transport Management

Recording Departures

▼
  • Go to Security → Transport Manifests
  • Find the manifest (shows transporter name, vehicle registration, batch IDs)
  • Verify the vehicle and driver match the manifest
  • Mark as Departed — timestamp recorded

Recording Arrivals

▼
  • When vehicle arrives, mark as Arrived
  • System calculates actual duration automatically
  • If actual > 130% of expected → TRANSPORT_TIME anomaly is created
  • All senior roles + you are notified
  • Document any irregularities
Late transports are flagged automatically. If a vehicle takes more than 130% of its expected travel time, the system creates an anomaly. This is a potential diversion indicator.
Destruction Witnessing

SAPS Destruction Events

▼

Cannabis destruction requires a SAPS officer witness. Your role:

  • Be present when the SAPS officer arrives
  • Verify their identity: name, badge number, station
  • The Facility Manager records the event in TnT-ZA
  • You verify the weight matches what is being destroyed
  • If the destroyed weight differs from the system record by >2%, an INVENTORY_DISCREPANCY anomaly fires
Monitoring

Checking Open Anomalies

▼
  • Go to Security page
  • Open anomalies are listed with type, severity, and description
  • You can view details but only FM+ can resolve them
  • Report anything suspicious to the Facility Manager
