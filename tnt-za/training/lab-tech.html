Lab Tech

TnT-ZA Training Guide

You test batches, submit results, and generate Certificates of Analysis. Your work determines whether product can be released or must be quarantined.

A single failed test auto-quarantines the entire batch. All 8 test types must pass before a COA can be generated.
The 8 Required Tests
Every batch requires ALL of these before it can be released:

POTENCY · PESTICIDE · HEAVY_METALS · MICROBIAL
MYCOTOXIN · RESIDUAL_SOLVENTS · MOISTURE · FOREIGN_MATTER
Workflow

Step 1: Check Pending Batches

▼
  • Go to Lab page
  • Batches show a progress indicator: X/8 tests completed
  • Quarantined batches are highlighted in red — these need retesting
  • Prioritize quarantined batches

Step 2: Submit Test Results

▼
  • For each test type, submit: test type, result data (values + thresholds), passed (yes/no)
  • Result data is structured: value, threshold, unit (e.g., 22.5% THC, threshold 15%)
  • If passed = false → the batch is automatically quarantined
  • The Facility Manager is notified

Step 3: Generate COA

▼

Only possible when all 8 tests have passed.

  • The system generates a PDF Certificate of Analysis
  • PDF contains: batch number, strain, facility, all 8 test results with values
  • A QR code is embedded linking to the public provenance page
  • The batch status changes to RELEASED
  • Anyone can scan the QR on the package to verify

Flagging for Retest

▼
  • If you doubt a result (instrument error, contaminated sample)
  • Flag the specific result for retest
  • The batch is automatically quarantined until new results come in
  • All previous results for that test type remain in the audit trail

Viewing Batch Detail

▼
  • Go to Batches → click a batch
  • See the 8-test grid showing pass/fail/pending for each type
  • See the chain of custody — every container event linked to this batch
  • See the plants that make up the batch
