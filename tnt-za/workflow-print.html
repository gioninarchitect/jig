Rooting14 days

Transplant to GreenhouseBayGrid

  • Record cm growth measurements weekly
  • Feeding concentration increases gradually through veg period

Cultivation — Steps 6 to 8

Flip through flowering to harvest. Harvest is the critical handover point from Cultivation to Processing.

6
Flip
  • Light schedule change: 18/6 → 12/12 — triggers flowering response
  • Record flip date precisely — all subsequent timelines calculated from this
  • Stretch period begins: rapid vertical growth for 2-3 weeks
  • Measure stretch cm per strain — builds predictive growth database
  • Continue regular feeding + environmental monitoring
CULTIVATOR
7
Flower56 days (8 weeks)
  • 8-week flowering period (varies by strain)
  • Monitor trichome development: clear → milky → amber (determines harvest timing)
  • Monitor pistil color: white → orange/brown
  • Full bloom nutrient feeding schedule maintained
  • Flush with plain water 1-2 weeks before target harvest (removes nutrient buildup)
  • Environment: temperature 20-26°C, relative humidity 40-50%
  • Target harvest date calculated from flip date + strain average flower time
CULTIVATOR + IRRIGATION TECH☐ Trichome check
8
⚡ Harvest — Critical HandoverQR Scan
  • Cut plants at base — all material from bay harvested together
  • Record WET WEIGHT per plant — this is the baseline for all subsequent weight tracking
  • Assign harvested material to BIN containers (BIN-xxx) — each container gets QR
  • Create production batch: B-2026-xxx — links all plants, strain, grow data
  • Clear bay in BayGrid → status returns to EMPTY → available for next cycle
  • HANDOVER: Cultivator signs off → Processing Manager (JR) receives
  • This is the most important weight checkpoint — wet weight at harvest is the reference for all loss calculations
CULTIVATOR → PROCESSING MGR⚖ WET WEIGHT RECORDED

Wet Material ReceivingQR Scan

  • Handover documented: Cultivator name + Processing Manager name + timestamp
  • Any weight variance at this point → immediate ANOMALY → alerts FM + Tenant Admin + Super Admin
PROCESSING MGR (JR)⚖ VERIFY WET WEIGHT
10
Drying (DRS)14 days
  • Hang whole plants or branches on drying racks — assigned RACK-xxx IDs
  • Drying room environment: 18-21°C temperature, 55-65% relative humidity
  • Daily monitoring: temperature + humidity logged in TnT-ZA
  • Expected moisture loss: approximately 70-75% of wet weight
  • Ready indicator: small stems snap cleanly (not bend)
  • Record DRY WEIGHT when removing from racks — second weight checkpoint
PROCESSING MGR⚖ DRY WEIGHT OUTQR on Rack

Debuc — JR ONLYBarcode

  • Every bin scanned with barcode scanner — weight logged in TnT-ZA
  • Remaining stem material and waste weighed + documented separately
  • Total bin weight + waste weight must equal dry weight input (±2%)

Processing — Steps 12 to 14

Trim sessions through QA sign-off and batch release. The store/QA step is the final gate before any product can be sold.

12
TrimBarcode
  • Multiple TRIMMERS work simultaneously — each assigned a weighed bin
  • Weight IN: each trimmer receives a bin — weight recorded at handover
  • Weight OUT: each trimmer returns trimmed product — weight recorded
  • Waste: trim waste (sugar leaves, stems) weighed separately per trimmer
  • Partial completion allowed — trimmer can finish bin next day (leftover tracked)
  • Reconciliation rule: Weight IN = Weight OUT + Waste Weight (±2%)
  • Any variance outside tolerance → ANOMALY → requires investigation
  • Trimmer performance tracked: grams per hour, accuracy, completion rate
TRIMMERS (T1, T2, T3...)⚖ IN + OUT + WASTE
13
Cure14+ days
  • Trimmed product placed into cure containers — assigned CURE-xxx IDs with QR
  • Minimum 2-week curing period in controlled environment
  • Burping schedule: open containers daily (first week) → every 2-3 days (second week onward)
  • Target humidity inside container: 62% (use humidity packs if needed)
  • Additional 5-10% moisture loss during curing is expected
  • Record final cure weight when curing period complete
PROCESSING MGR⚖ CURE WEIGHTQR on Container
14
Store & QA Sign-off — GATEQR Scan
  • Move cured product to secure storage vault
  • Lab Testing: ALL 8 test types must PASS — potency, pesticide, heavy metals, microbial, moisture, mycotoxin, residual solvents, terpene profile
  • If ANY test fails → batch status: QUARANTINED → 7 auto-tasks created (isolate, notify SAHPRA within 24hrs, sample for retest, document, root cause, cleaning review, equipment check)
  • All 8 tests PASS → Certificate of Analysis (COA) generated automatically (PDF + embedded QR code)
  • QA Inspector reviews batch: visual inspection, documentation check, weight verification
  • QA Inspector sign-off → batch status: RELEASED → available for sale
  • Final sellable weight recorded — this is the definitive inventory number
QA INSPECTOR + LAB TECH⚖ FINAL SELLABLE WEIGHT

SAHPRA Compliance — Automated Touchpoints

10 compliance triggers automated through the TnT-ZA task and SOP system.

  • Batch Created — Auto-logged in SAHPRA production register
  • Quarantine Triggered — 7 auto-tasks: isolate batch, notify SAHPRA within 24 hours, collect retest samples, document details, begin root cause analysis, review cleaning schedule, check equipment calibration
  • Destruction Event — SAPS officer must witness. Checklist: weigh material, officer present (name, badge, station), photograph process, both parties sign certificate, file in compliance records, update INCB quota
  • COA Issued — Automatically attached to batch record. PDF with QR code. Required before any sale
  • Dispatch — Transport manifest with Section 22C permit reference number
  • Monthly INCB Reconciliation — Auto-task: reconcile produced vs destroyed vs in-stock vs dispatched. Submit to SAHPRA by 5th of following month
  • Spray Application — Per-batch SOP: chemical name, dilution ratio, PPE worn, applicator name, start/end time, re-entry interval
  • Equipment Calibration — Weekly SOP: scales, pH meters, EC meters, temperature/humidity sensors. All readings logged
  • Daily Facility Inspection — Entry/exit logs complete, cameras operational, PPE compliance, pest trap checks, fire safety
  • Room Cleaning — Per room per day: grow room, dry room, trim room, pack room. Each has SAHPRA-compliant checklist
