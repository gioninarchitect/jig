The grow calendar is yours — and it now does the work for you

A few changes to make running the cultivation cycle faster and quieter.

The grow calendar is now Head-of-Cultivation only. You build and adjust it — the Cultivation Supervisor and other roles can view it but can't change it. One owner, no surprises.

1Adjust phase lengths — everything else moves itself

On the Grow Calendar, you can now tune veg / flower days. When you change a phase, the whole calendar re-flows automatically — every downstream phase, task and reminder shifts to match. You see a live harvest-date preview ("new harvest ≈ 12 Aug, 5 days earlier") before you confirm, and a reason is captured for the record.

2Shift the whole cycle

If rooting is delayed or a heat event hits, Reschedule cycle shifts the start date and re-flows the entire plan in one action. (If harvest moves earlier, a change-control note is logged automatically — GMP stays clean.)

3A much quieter board

  • The "Build grow calendar" reminders no longer pile up — it's one at a time now (genesis had stacked up ~58; cleared to one).
  • Each new clone tray creates ~5 tasks instead of ~25 — the daily clone-room temp/humidity is one tray task, not one per day.

4Harvest approvals

Harvest requests are approved by you and QA — so the call stays with the people who own the crop and the quality.
